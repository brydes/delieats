# 🥑 DeliciasSinGlucosa - Web de Recetas Keto y Conversor de Edulcorantes

Un portal web responsivo y funcional diseñado para ofrecer recetas dulces saludables adaptadas a personas con diabetes o con alimentación baja en carbohidratos (Keto). Además, incluye una herramienta interactiva para calcular equivalencias de edulcorantes respecto al azúcar tradicional.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio.
* **Tailwind CSS (vía CDN):** Estilizado responsivo, moderno y optimizado.
* **JavaScript (Vanilla):** Lógica interactiva para la calculadora de edulcorantes y manipulación del DOM.
* **FontAwesome:** Iconografía vectorial.

---

## 🧮 Características Principales

1. **Conversor Interactivo de Edulcorantes:**
   * Permite calcular la equivalencia exacta de azúcar a **Eritritol**, **Stevia Pura** o **Fruto del Monje (Monk Fruit)**.
   * Proporciona recomendaciones técnicas sobre el uso de cada sustituto para repostería.

2. **Sección de Recetas Gratuitas:**
   * Visualización de muestras de postres saludables con ingredientes y certificaciones de impacto glucémico.

3. **Integración Comercial:**
   * Botón de llamada a la acción (CTA) vinculado a oferta de infoproducto digital en Hotmart.
